## 書き方

- **ファイル名は英語、連番付き。** `NNNN-kebab-case-in-english.md`
- **中身は日本語でよい。** 定義もこの参照実装も日本語で書かれている
- 新しい ADR を追加したら、この索引に1行足す

ファイル名を英語にするのは、URL・パス・grep・ツールの扱いが素直になるためである。ファイル名は識別子であり、読み物ではない。
